# AGENTS.md

Este é um monorepositório agregador. Os projetos upstream ficam em `components/`.

## Regras permanentes
- Leia `SOURCES.lock.json` antes de atualizar componentes.
- Preserve licenças e avisos de terceiros.
- Alterações de integração pertencem a `integrations/` ou `orchestrator/`.
- Não inclua segredos.
- Rode os testes do componente alterado.
- Use os skills em `skills/`.
